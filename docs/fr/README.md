Bienvenue dans la documentation technique en français de **SYNAPSE MOCK SERVER**.

**SYNAPSE MOCK SERVER** est un banc d'essai client et simulateur de télémétrie pour le protocole Synapse HFT dans l'écosystème CARINA. Conçu selon les principes de la **Clean Architecture** et de **SOLID**, il permet de valider et de tester les contrôleurs intelligents de feux de signalisation via gRPC en temps réel.
