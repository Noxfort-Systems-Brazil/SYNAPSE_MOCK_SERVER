Bienvenido al centro de documentación técnica en Español de **SYNAPSE MOCK SERVER**.

**SYNAPSE MOCK SERVER** es el generador de carga de telemetría y banco de pruebas de cliente para el protocolo Synapse HFT dentro del ecosistema inteligente CARINA. Desarrollado en Python bajo los principios de **Clean Architecture** y **SOLID**, permite evaluar, estresar y validar controladores semafóricos inteligentes mediante gRPC en tiempo real.
