Добро пожаловать в русскую техническую документацию **SYNAPSE MOCK SERVER**.

**SYNAPSE MOCK SERVER** — это генератор нагрузки и клиентский тестовый стенд для протокола Synapse HFT в экосистеме CARINA. Построенный на принципах **Clean Architecture** и **SOLID**, он предназначен для тестирования интеллектуальных светофорных контроллеров по протоколу gRPC в реальном времени.
