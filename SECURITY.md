# Security Policy

## Supported Versions

Currently, SYNAPSE MOCK SERVER is in active development. Only the latest release and the current `main` branch are officially supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.2.x  | :white_check_mark: |
| v1.1.x  | :white_check_mark: |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**IMPORTANT:** SYNAPSE MOCK SERVER simulates telemetry for traffic control infrastructures. Vulnerabilities in gRPC deserialization, memory buffers, or scenario file ingestion can affect connected testing environments and digital twins.

**DO NOT** disclose vulnerabilities publicly on GitHub Issues.

If you discover a security vulnerability, please report it immediately by emailing:
**security@noxfort.com** *(Noxfort Systems Security Team)*.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates regarding remediation. If a patch is deployed, you will be credited in our release notes (unless you prefer to remain anonymous).
